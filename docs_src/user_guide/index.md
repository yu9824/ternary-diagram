# User guide

Task-oriented guides to `ternary-diagram`. Each page explains one goal with runnable examples.

- [Getting started](getting_started.md): Install the package, draw and save a first diagram, and pass compositions.
- [Customizing the diagram](customizing.md): Change the border, grid, tick labels, axis titles and vertex labels.
- [Drawing phase diagrams](phase_diagrams.md): Shade phase regions, label them and control how they overlap.
- [Heatmaps and contour maps](heatmaps_and_contours.md): Choose between colored scatter plots, contour maps and heatmaps.
- [Layout and colorbars](layout_and_colorbars.md): Control the automatic layout adjustment and colorbars.
- [Migrating to v4.0.0](migration_v4.md): Update code for the defaults that change in 4.0.0.
